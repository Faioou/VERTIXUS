Modo administrador local

As perguntas são gravadas em data/perguntas.json e as expressões informais em data/expressoes.json. As imagens novas são copiadas para imagens/.

Depois de criar ou editar perguntas, no terminal execute:

git add .
git commit -m "Atualizar perguntas"
git push

Quando o GitHub Pages terminar a publicação, os outros dispositivos passam a ver os dados atualizados.
